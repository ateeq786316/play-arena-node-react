# 086 — Landing Page + Features

**Type:** AFK | **Blocked by:** 002

## What to build

Build the public landing page at `/` (no auth required). **Hero Section**: full-width background image or gradient, headline "Book. Play. Compete." or similar value prop, search bar (same as public search), two CTAs "Book a Ground" → `/grounds`, "List Your Venue" → `/for-owners`. **Sport Categories**: horizontal scrollable row of sport cards (Cricket, Football, Badminton, Basketball, Squash, Tennis, Futsal) with icons, clicking filters search by sport. **Featured Grounds**: 6-card grid of top verified grounds. **How It Works** section: 3-step process for Players (Find → Book → Play) and 3-step for Owners (List → Manage → Earn). **For Players** section: benefits, features, screenshots, [Learn More] → `/for-players`. **For Owners** section: benefits, subscription plans preview, [Learn More] → `/for-owners`. **CTA Section**: "Ready to play?" → Search CTA, "Own a venue?" → List CTA. **Footer**: links to About, Contact, FAQ, Terms, Privacy, social media.

## Acceptance criteria

- [ ] Hero section with headline, search, CTAs
- [ ] Sport categories row
- [ ] Featured grounds grid
- [ ] How It Works section (Players + Owners)
- [ ] For Players and For Owners sections
- [ ] CTA section
- [ ] Footer with links
- [ ] Responsive (mobile-first)
- [ ] Loading, error states for dynamic sections
