# 056 — Admin Finance Reports

**Type:** AFK | **Blocked by:** 009

## What to build

Build **Admin Finance Reports** at `/admin/finance`. **KPI Row**: Total Revenue (all time), Total Bookings, Platform Commission Earned, Active Subscriptions Revenue. **Revenue Chart**: daily revenue (bar chart), platform commission vs owner payout (stacked bar). **Revenue Table**: Date, Bookings, Gross Revenue, Commission, Net to Owners, columns. **Filter**: date range, country/city. **By Ground** table: Ground Name, Owner, Bookings, Revenue, Commission. **Export**: CSV.

## Acceptance criteria

- [ ] KPI cards with financial metrics
- [ ] Revenue charts (bar, stacked bar)
- [ ] Revenue table with date range filter
- [ ] By Ground breakdown table
- [ ] CSV export
- [ ] Loading, error, empty states
