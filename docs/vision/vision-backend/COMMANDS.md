## Default Commands

| Command | Description |
|---------|-------------|
| `npm start` | `tsx server.js` - Start server |
| `npm run dev` | `tsx watch server.js` - Start with auto-reload |
| `docs/vision/postman-collection.json` | Import in Postman to test all API endpoints |
| `npx prisma migrate dev` | Create/apply Prisma migrations |
| `npx prisma generate` | Regenerate Prisma client |
| `npm test` | Run tests |
| `npm run lint` | Run linter |
